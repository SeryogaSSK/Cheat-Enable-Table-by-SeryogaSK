## Installation & Usage

1. Download the desired `.CT` file from this repository.
2. Install and launch Cheat Engine.
3. Start the corresponding game.
4. Open the downloaded `.CT` file in Cheat Engine.
5. Click the process selection button in Cheat Engine.
6. Select the running game process.
7. Enable the desired cheats by checking their corresponding boxes.
8. Modify available values where applicable.

**Important:** Some cheats may only work after loading a save, entering a level or reaching a specific gameplay state.

## Troubleshooting

### Cheat Engine cannot find the game process
- Make sure the game is running.
- Check that you selected the correct process.
- Restart Cheat Engine and the game if necessary.

### A cheat does not activate
- Verify that you are using the supported game version.
- Make sure the game is in the correct gameplay state.
- Check whether the cheat requires a specific level, save or gameplay condition.

### Script activation failed
- Make sure Cheat Engine is attached to the correct process.
- Check whether a recent game update changed the executable.
- Restart the game and try again.

### Cheats stop working after a game update
- Game updates can change memory addresses and code patterns.
- The table may need to be updated.
- Check this repository for a newer version.

### Game crashes or behaves unexpectedly
- Disable all active cheats.
- Restart the game.
- Restore your save backup if necessary.
- Report the issue with the game version and table version.
