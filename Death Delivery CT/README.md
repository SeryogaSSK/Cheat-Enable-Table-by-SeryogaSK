## Installation
1. Download the `.CT` file from the repository.
2. Launch **Death Delivery**.
3. Open the `.CT` file with Cheat Engine.
4. Attach Cheat Engine to the game's process.
5. Enable the desired options and modify the available values.

## Usage & Important Warnings
- Make sure the game is running before activating any cheats.
- Enable scripts only when the corresponding game process is attached.
- Some values may require entering a level or loading a save before they become available.
- Avoid changing multiple values simultaneously if you are unsure how they interact.
- Use timer-related options carefully, as they may affect level progression.
- Disable active scripts before closing the game or switching to another game session.
- Some cheats may cause unexpected behavior, crashes, or progression issues.
- Use at your own risk. Creating a backup of your save files is recommended.

## Troubleshooting
- **Cheat not working:** Verify that you are using the supported game version.
- **Script activation failed:** Make sure the correct game process is attached.
- **Game update:** Wait for a compatible table update if the game has changed.
- **Game crash:** Disable the active scripts and restart the game.
