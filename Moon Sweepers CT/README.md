## Features

### 👤 Player
- **Dust Kilograms per Litre** – Modify the amount of dust collected per litre.
- **Dollars per Kilogram** – Adjust the money earned per kilogram.
- **Run Speed** – Customize the player's running speed.

### 🧹 Cleaning Tool
- **Cleaning Width** – Modify the cleaning width.
- **Cleaning Depth** – Modify the cleaning depth.
- **Cleaning Edge Width** – Adjust the cleaning edge width.
- **Removal Rate** – Customize the dust removal rate.

## Requirements
- Moon Sweepers (Version 1.0.1)
- Cheat Engine

## Installation
1. Download the `.CT` file from the repository.
2. Launch **Moon Sweepers**.
3. Open the `.CT` file with Cheat Engine.
4. Attach Cheat Engine to the game's process.
5. Enable and modify the available options.
